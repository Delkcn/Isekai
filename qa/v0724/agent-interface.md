# 0.7.24 — 文件锁定与双手施法

本版以用户的新要求覆盖 0.7.15 的单手、较小弹体和单环微弱命中反馈。只做动画与命中记录，不打开、移动、修改或删除目标文件。

## 用户入口

右键角色 → **双手施法 · 魔法弹 → 选择桌面文件并施法…**。

列表只读枚举 Windows 桌面视图中的文件及快捷方式。用户必须选中一项并点击“锁定并施法”。后续可用“向所选文件施法”再次请求。不会自动选择文件，不改变 Explorer 的选择状态、排列方式或图标位置。目录和虚拟系统图标不列为文件目标。

目标为所选文件桌面图标的中心。正式施法前需要图标可见；若被其他窗口遮挡，会提示显示桌面后重试。任意文件若没有桌面图标，现阶段无法定位它的屏幕目标；可以选择其桌面快捷方式。

## 接口

```csharp
public interface IFileCastAction : IMagicCastAction {
    Guid CastFile(string path);
}
// Existing IMagicCastAction:
// Guid Cast(PointF targetPosition);
// void CancelCast();
// event EventHandler<ProjectileHitEventArgs> ProjectileHit;
```

三个方法在 UI 线程调用。`CastFile` 先验证文件确实存在于桌面视图，再委托 `Cast` 完成必要跑位、刹停、转身和动作互斥；整个过程保留同一个请求 Guid，不要求调用方重发。点坐标接口与“动作预览（不锁文件）”子菜单保留给检查与后续 Runtime；实际文件入口要求用户明确选择。

`ProjectileHitEventArgs` 保留 `RequestId`、`Origin`、`TargetPosition`，新增只读 `TargetFile`；点坐标预览的该字段为 null。每枚法弹至多发出一次事件，按既有方式记录到 `%LOCALAPPDATA%/IsekaijouchoPet/projectile-hits.log`。没有模型依赖、程序启动控制器或目标文件写入。

## 锁定与取消

`DesktopFileTarget` 复用 Shell 文件身份，读取 ListView 的 LVIR_ICON 图标矩形并以该控件 ClientToScreen 换算，取实际矩形中心。目标身份和屏幕中心锁定在请求时；施法中每 0.10 秒验证一次，释放及命中事件提交前再次验证。

文件消失、Shell 图标消失或图标中心改变时取消，既不向旧坐标继续宣告命中，也不修改文件位置。此版不做追踪移动目标的制导弹道。跑位期间允许控制器进行横向移动与转身，竖向窗口变化、拖动、尺寸 / 显示器布局变化及显式切换动作取消；进入施法后仍禁止位置和朝向突变。成功命中后释放文件锁定，爆开效果在原命中点完成。

目标过近、掌后或当前角度超过自然范围时，先保留请求并在当前屏幕内横向寻找站位，以已有跑步动作到达。优先选择 ±50° 内的近处站位，不足时尝试 ±60°；原地已在 ±65° 范围内则不跑位。自然刹停、转身并验证实际释放射线后，自动进入施法。若无可用站位、超过 3 次重规划或 45 s 有效等待上限则提示并取消，不让弹体穿过角色。选择窗口打开期间禁止自动游走和搬运开始。右键菜单暂停动作；关闭视觉效果仍推进法弹并记录命中。

## 动作与效果

- 0.10 s 开始抬手，时长约 0.659 s；0.759–1.759 s 蓄力；1.759–1.939 s 沿目标方向前推，1.929 s 释放；放手 1.00 s，2.939 s 复位。抬手、蓄力、放手速度各为 0.7.18 的 70%。
- 蓄力时双手后缩 0.051 倍人物尺寸，接近原幅度两倍；前推末端完全直臂，释放瞬间低于 18°。固定骨长与推送阶段各掌局部路径、朝向约束保持，路径整体旋转到目标方向，不通过伸长手臂获得更大幅度。放手中段加入近 / 远侧约 42° / 38° 的自然屈肘，肩部配合下落，首尾连续回到原姿势。
- 光球和 24 个向心粒子均使用当前双掌共同锚点，直到精确释放时刻。粒子外圈范围、亮点与短光线增强，最后一批在释放时融入；光球半径、亮度、飞行速度和尾迹不改。
- 命中复用 ArcheryArt.Impact，通过纯绘制的零距离 MagicArrow 参数适配到指定目标中心；尺寸为普通弓箭的 70%，三重金色波纹相隔 0.10 s，并带同款金色星光，寿命为 0.85 s。适配对象不接收事件，也不执行文件操作。
- ProjectileHit 仍在法弹到达时触发至多一次，不等待视觉效果结束。目标文件移动 / 消失、窗口位置 / 朝向改变和其他取消策略保持。独立特效窗口扩展边界以容纳更大命中光效。
- 头部随文件相对头部的仰俯角轻微抬低，最大 24°；不重画瞳孔或人物素材。双掌推送方向与实际释放核心到文件中心的连线一致。
- 文件中心读取沿用 0.7.21 已验证实现，本轮未再次读取真实桌面或替用户选择目标施法；混合 DPI 多屏仍待硬件验收。

本版统一跑步速度为 198 × 人物尺寸 / 300 px/s，是 0.7.23 的 150%。普通走路仍为 36 px/s。施法跑位、普通跑步及跑动搬运共用此速度入口；加速 / 刹停曲线和动作参数不变。

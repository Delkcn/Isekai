## 运行

直接运行项目根目录 IsekaijouchoPet.exe，旁边保留 assets 目录。本版使用已展开的资源，不需要 character.pack。
如果旧版桌宠仍在运行，请先从系统托盘退出旧版；单实例机制不变。
需要 Windows 和 .NET Framework 4.8。

## 具体边界

这是可运行的 2D/2.5D 预览版，不是完整的 3D 人物。
转身几何连续、与走路的衔接帧完全一致，但不同方向材质切换仍能看出细节变化。
睡眠关键图之间使用轮廓配准与混合，手部遮挡发生变化时仍可能出现短暂叠影。
补充腿部是为移动时显露的被遮挡区域绘制的辅助层，并非从原图恢复出的隐藏像素。
推手、睡姿和摸头的原画都保存在资源板中；运行时推手和摸头沿用程序驱动，
不会把整张推手或摸头插图生硬替换到动作中。

- src/Rendering/WalkArt.cs：左右腿部绑定和手臂变形。

- src/Rendering/SkeletalTurn.cs：转身骨骼、网格和新版材质坐标。
